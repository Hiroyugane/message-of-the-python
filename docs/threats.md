# Threats and how each is covered

Every threat of the threat model with the tests that cover it, or the reason it is accepted.
`tests/test_threats.py` fails when a threat id has neither, when the ids have a gap, or when a
test named here no longer exists. Tests marked `needs_linux_owner` run as root in the containers
(`tools/container_test.py`, the CI job `test-container`).
