Header fonts of MOTP, the message of the python

The file format of all four fonts is FIGfont version 2, as described in the FIGfont
standard.


motp-block.flf and motp-block-small.flf
---------------------------------------

Original fonts made for MOTP in 2026. Every character of these files is computed by
tools/make_fonts.py from pixel masks drawn in that script (the drop shadow of motp-block
is computed from the masks too); no existing font file was copied. They are part of MOTP
and are covered by its licence, the GNU General Public License, version 3 or (at your
option) any later version; see the LICENSE file at the root of the repository.


big.flf and small.flf
---------------------

FIGlet's fonts "Big" and "Small" by Glenn Chappell, taken from the package
Debian 12 figlet 2.2.5-3+b1 (/usr/share/figlet). The glyphs are unchanged. The e-mail
addresses in the comment lines were removed and one comment line naming that change was
added, as the fonts' own comment lines permit a modifier to do. SHA-256 of the original
files as shipped in that package:

0065328daf2a6eb49ff274f8d27a195e7b748cb51cad992b0aa96839ccb5169d  big.flf
c275f3cf053af2eec87804fe60ad5cc865dbb25ea65d5cbbe09a27f332c714f0  small.flf

tools/make_fonts.py --import-figlet <dir> checks these checksums and repeats the change.
